# 采购校招方法论

## 使用原则

本文件仅作为采购岗位面试的通用兜底，不覆盖用户提供的采购品类、供应商、成本数据、合同条件、个人权限和项目事实。用户事实优先；缺失内容使用 `【待补充】`，不得编造降本金额、供应商表现或谈判结果。

## 核心目标

采购的核心不是单纯压价，而是在质量、成本、交付、服务、风险和合规之间取得全生命周期最优，保障业务连续性并构建健康供应体系。

- 准确理解内部需求和技术/服务规格。
- 建立透明、可比较的供应市场与供应商信息。
- 获得有竞争力的总成本和合同条件。
- 保障质量、交付、服务与供应连续性。
- 遵守授权、招采、廉洁和审计要求。

## 业务链路

```text
需求澄清 → 规格与预算 → 供应市场分析 → 寻源 → 准入与询比价/招标 → 评审谈判 → 合同 → 下单交付 → 验收付款 → 绩效与风险管理
```

面试应追问需求真实性、决策标准、比较口径、权限边界、异常处理和复盘，而非只问谈判技巧。

## 能力模型

| 能力 | 校招考察重点 |
|---|---|
| 需求理解 | 能否区分必要规格、偏好和隐性约束 |
| 市场分析 | 能否理解供需格局、成本驱动和替代方案 |
| 供应商评估 | 能否从质量、成本、交付、服务和风险综合判断 |
| 成本分析 | 能否关注总拥有成本，而非只看采购单价 |
| 谈判沟通 | 能否准备筹码、底线、替代方案并维护关系 |
| 合同意识 | 能否识别交付、验收、付款、质保和违约条款 |
| 协同推进 | 能否协调需求、技术、质量、法务和财务 |
| 合规风控 | 能否遵守流程、回避利益冲突并保留决策证据 |

## 指标

- 成本：采购单价、总拥有成本、预算偏差、可验证降本、付款条件。
- 质量：来料合格率、不良率、退换货率、质量事故和整改关闭率。
- 交付：准时交付率、交付周期、缺货率、紧急采购占比。
- 供应商：绩效评分、集中度、备选覆盖率、改善完成率。
- 流程效率：寻源周期、合同周期、订单准确率、流程合规率。
- 护栏指标：断供风险、质量损失、库存积压、单一来源依赖、廉洁与审计风险。

降本必须说明基准价格、数量、规格、周期和是否牺牲质量或账期。

## 项目深挖

```text
需求与约束 → 市场信息 → 供应商池 → 评估标准 → 个人职责 → 谈判/协同动作 → 成本质量交付结果 → 风险控制 → 复盘
```

重点追问：

- 用户是否有决策权，还是负责数据、流程或协同支持。
- 供应商比较是否在同规格、同数量、同交付条件下进行。
- 谈判前的目标、底线、BATNA 和筹码是什么。
- 降价是否带来质量、交付、账期或售后风险。
- 决策过程是否符合授权、比价、招标和审计要求。

## 场景题

- 最低价供应商质量不稳定：按总成本和风险评分，不以单价直接决策。
- 核心供应商临时延期：确认影响，启动备选、替代料、库存和交付协商方案。
- 业务方指定供应商：澄清理由并执行合规评估、比价或单一来源审批。
- 原材料价格上涨：拆成本结构，评估锁价、替代、批量、账期和多源策略。
- 新供应商报价低：先做资质、样品、小批试单、产能和财务风险验证。

## 答案框架

采购项目题：

```text
需求与约束 → 市场/成本分析 → 评估标准 → 我的职责和动作 → 谈判或协同 → 结果 → 质量交付与合规护栏 → 复盘
```

采购场景题：

```text
确认需求与影响 → 收集事实 → 比较总成本和风险 → 形成备选方案 → 按权限决策 → 监控履约 → 留痕复盘
```

没有实际授权或结果时，应准确描述参与边界和建议方案。

## 正反例

正例：

> 我没有最终定标权，主要负责统一报价口径和供应商评估。我把单价、运费、账期、良率和售后纳入总成本比较，并建议先小批试单；这样避免把低报价直接当成真实降本。

反例：

> 我通过强势谈判把供应商价格压到最低，为公司节省了很多成本。

反例的问题：职责、基准、金额、质量交付影响、谈判方式和合规边界均不清楚。

## 风险边界

- 不虚构降本比例、合同条款、供应商名单或个人决策权限。
- 不把压价作为唯一价值，不以牺牲质量、交付、劳动权益或环境责任换取结果。
- 不规避招标、审批、比价、关联关系披露和审计留痕。
- 不接收不当利益，不泄露底价、竞标信息和商业秘密。
- 不在未经验证时建议单一来源或高集中度采购。
- 方法论仅用于兜底结构，不覆盖用户事实、企业制度和法律法规。
