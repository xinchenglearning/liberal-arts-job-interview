# 销售与商务拓展校招方法论

## 使用原则

本文件仅作为销售与商务拓展岗位面试出题、追问和答题的兜底框架，不覆盖用户提供的客户、行业、产品、价格、合同、业绩、渠道、个人职责和项目事实。用户事实与 JD 优先；信息缺失时使用 `【待补充】`，不得把通用销售动作、虚构客户关系或假设成交结果包装成用户经历。

销售与商务拓展需先区分岗位重点：销售更关注从线索到回款的成交闭环，商务拓展更关注合作机会、资源互补、伙伴关系与长期业务增量。复合岗位应以 JD 中的实际职责为准。

## 核心目标

销售与商务拓展的核心不是单次说服，而是识别有价值的客户或伙伴需求，建立可信关系，设计双方可持续的价值交换，并在合规、利润和交付可行的边界内推动成交、合作与长期增长。

- 识别目标市场、客户或合作伙伴及其真实需求。
- 将产品或资源能力转化为清晰的业务价值。
- 管理线索、商机、关键人、方案、谈判和决策节奏。
- 协调内部资源，确保承诺可交付、结果可回收。
- 兼顾收入、利润、回款、续约与长期关系。

## 业务链路

销售常见链路：

```text
市场与客户分层 → 线索获取 → 资格判断 → 需求诊断 → 方案与价值呈现 → 异议处理 → 商务谈判 → 合同成交 → 交付协同 → 验收回款 → 续约与转介绍
```

商务拓展常见链路：

```text
战略目标 → 生态与伙伴识别 → 合作假设 → 价值与资源盘点 → 关键人建立 → 方案共创 → 商务条款 → 内部评审 → 签约落地 → 联合运营 → 效果复盘 → 合作深化
```

出题时应明确业务是 B2B、B2C、渠道、平台招商、广告、企业服务还是战略合作，并补充客单价、决策周期、交付复杂度等必要约束。

## 能力模型

| 能力 | 校招考察重点 |
|---|---|
| 市场与客户理解 | 能否识别目标客户、业务场景、决策链和优先级 |
| 需求诊断 | 能否从表面诉求追问目标、痛点、预算、时限和成功标准 |
| 价值表达 | 能否把产品功能或合作资源转化为客户可理解的业务价值 |
| 商机管理 | 能否判断机会质量、推进阶段、下一步动作和成交风险 |
| 关系建立 | 能否识别决策者、使用者、影响者并建立专业信任 |
| 谈判协商 | 能否准备目标、底线、筹码、替代方案并寻求双赢 |
| 内部协同 | 能否协调产品、方案、法务、财务、交付和管理层 |
| 结果与复盘 | 能否说明收入、利润、回款、留存及失单原因 |

## 指标

- 获客：有效线索数、线索成本、目标客户覆盖率、首次响应时长。
- 漏斗：线索转商机率、方案率、报价率、赢单率、阶段转化率、销售周期。
- 经营：合同额、收入、毛利率、客单价、目标达成率、预测准确率。
- 现金：回款额、回款周期、逾期率、坏账风险。
- 客户：续约率、增购率、流失率、转介绍率、客户满意度。
- 商务合作：有效伙伴数、合作上线率、联合项目产出、渠道贡献、合作续签率。
- 护栏指标：折扣率、履约成本、投诉、退款、合规事件、过度承诺和客户集中度。

指标必须说明统计口径、周期、基线和个人贡献；合同额不等于确认收入，签约不等于回款，合作数量不等于有效业务价值。

## 项目深挖

```text
业务目标 → 客户/伙伴选择 → 需求与决策链 → 机会判断 → 我的职责 → 关键推进动作 → 谈判与内部协同 → 成交/落地结果 → 回款或长期价值 → 复盘
```

重点追问：

- 客户或伙伴为什么值得投入，资格判断依据是什么。
- 对方真实需求、预算、决策人、时间表和阻力如何确认。
- 用户本人负责获客、需求、方案、关系、谈判还是协同，权限边界在哪里。
- 关键异议是什么，如何用事实和价值而非施压推进。
- 成交或合作结果是否牺牲利润、交付能力、合规或长期信任。
- 失单、延期或合作未落地的根因是什么，下一次如何改进。

## 场景题

- 客户只关注低价：澄清比较口径与成功标准，呈现总价值和差异，守住利润与交付底线。
- 关键客户迟迟不决策：复核需求紧迫度、决策链、预算和竞品，明确下一步承诺而非无效催促。
- 已承诺需求但内部无法按期交付：立即核实影响，停止追加承诺，给出替代方案并升级协同。
- 渠道伙伴带来大量低质量线索：重设目标客户、线索标准、激励和结算规则，按有效产出评估。
- 合作方希望绕过审批快速签约：说明合规边界，保留机会但按授权、法务和财务流程推进。

## 答案框架

销售或商务项目题：

```text
目标与客户/伙伴 → 需求及决策链 → 机会判断 → 我的职责 → 价值方案与推进动作 → 异议/谈判 → 结果口径 → 交付回款与风险 → 复盘
```

销售或商务场景题：

```text
澄清目标与约束 → 判断客户/机会质量 → 识别关键人和阻力 → 设计价值与备选方案 → 协调资源并推进 → 核心与护栏指标 → 风险升级与复盘
```

未提供真实客户、金额、转化率或权限时，只能说明判断与行动方法，不得补写成已成交事实。

## 正反例

正例：

> 我负责前期需求澄清和方案协调，没有最终定价权。我先确认客户的使用场景、决策人和上线期限，再把方案从功能清单改为对其流程效率的影响；对无法按期支持的需求明确标注边界，并协调交付团队提供分阶段方案。

反例：

> 我很擅长维护客户关系，通过不断沟通和灵活降价，最终拿下了一个大客户。

反例的问题：缺少客户选择、需求证据、个人职责、价值方案、金额口径、利润与交付风险，也把关系和降价当成唯一成交原因。

## 风险边界

- 不虚构客户名称、合同额、回款、转化率、合作资源、关键人关系或个人决策权。
- 不把团队收入、渠道自然成交或品牌势能全部归因于个人。
- 不以虚假宣传、隐瞒限制、私下承诺或过度折扣换取签约。
- 不泄露客户信息、底价、合同条款、竞品材料和商业秘密。
- 不绕过授权、招投标、反商业贿赂、数据隐私和合同审查要求。
- 不把签约视为终点，需关注交付、验收、回款、续约和客户长期价值。
- 本方法论仅用于兜底结构，不覆盖用户事实、公司销售制度、真实产品能力和法律合规要求。
